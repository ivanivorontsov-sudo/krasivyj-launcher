«Уют» 1.1.0

* Перетаскивание иконок во всех темах: иконка поднимается по долгому нажатию, соседи плавно расступаются; в док, между страницами (автолистание у края), на другую иконку — папка
* Папки: создание перетаскиванием, переименование, разбор, вынос иконок
* Цели сверху при перетаскивании: «Удалить с экрана», «О приложении», «Удалить приложение»
* Перетаскивание из меню приложений на главный экран; в «Плитках» — живая перестановка, анимированное изменение размера, вытягивание плитки из списка
* Раскладка хранится отдельно для каждой темы
* Анимация возврата: приложение «сворачивается» в свою иконку; поддержка GestureNavContract (жест «домой» складывает окно в иконку там, где прошивка это умеет)
* «Домой» без задержки: убран въезд экрана, быстрый fade окна, иконки не выгружаются при открытии приложений, дисковый кэш иконок, снимок списка приложений, кэш обоев
* Новые приложения автоматически появляются на главном экране (настройка «Главный экран»)
