«Уют» 1.2.0

* «Стоп-экран» прямо в лаунчере (Настройки → Стоп-экран): дневной лимит, пауза по расписанию, запрещённые приложения, приложения, разрешённые во время паузы, строгий режим, пароль с кодом восстановления (как в приложении «Стоп-экран»), история, перенос настроек из «Стоп-экран» (импорт JSON)
  * все темы, шрифты, эффекты и расстановка работают как обычно — запрещённые приложения просто исчезают с главного экрана, из меню, поиска, папок, дока и «Плиток»
  * открытые другим путём (уведомление, «Недавние», другое приложение) сразу возвращаются на главный экран — Уют, без всплывающих окон и без чужого лаунчера
* Эффекты перелистывания страниц, отдельно для каждой темы: Цилиндр (карусель), Куб, Переворот, Поворот, Приближение, Стопка, Волна, Без эффекта
* Возврат в иконку: пружинная анимация (~0,4 с) с карточкой, у которой скругление экрана перетекает в форму иконки, «приземлением» иконки и приближением сетки; запускается только когда окно Уюта реально видно — на realme / ColorOS с жестами она больше не проигрывается «вслепую»
* Подготовка анимации заранее (при уходе в приложение), ноль работы в onResume, окно появляется без fade
* Часы больше не вылезают за край ни в одной теме — на маленьких экранах и при крупном системном шрифте они аккуратно уменьшаются
