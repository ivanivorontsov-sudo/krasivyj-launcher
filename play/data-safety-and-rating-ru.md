# Google Play: «Безопасность данных» (flavor play)

- Собирает ли приложение или передаёт какие-либо типы пользовательских данных? — **Нет.**
  (Список приложений, настройки, выбранные фото и событие календаря обрабатываются только на устройстве и никуда не отправляются; «обработка на устройстве» по правилам Play не считается сбором.)
- Передача данных третьим лицам — **Нет.**
- Шифрование при передаче — неприменимо (данные не передаются). Отметить «данные не собираются».
- Можно ли запросить удаление данных — данные хранятся только на устройстве; удаляются вместе с приложением/очисткой данных.
- Политика конфиденциальности: URL (см. отчёт).
- Реклама: **нет**. Аккаунты/вход: **нет**. Доступ для проверки: не требуется.

Декларации разрешений (Play Console → Содержание приложения):
- Доступ к уведомлениям (NotificationListenerService): только счётчики на значках, включается пользователем вручную. Декларации в Console не требует, но указать в описании.
- READ_CALENDAR: показ ближайшего события на плитке, по запросу.
- REQUEST_DELETE_PACKAGES: удаление приложения из меню лаунчера (системный диалог).
- QUERY_ALL_PACKAGES — не используется (только <queries>). Exact alarm / full-screen / accessibility / VPN / overlay / battery-optimization / READ_MEDIA_* — отсутствуют.
- Категория: «Персонализация». Целевая аудитория: 18+ (или 13+), не для детей. Новостное приложение: нет. Госприложение: нет. Финансы/здоровье: нет.

# Возрастной рейтинг (анкета IARC)
Категория анкеты: «Утилиты, продуктивность, общение и прочее» (Utility/Productivity).
- Насилие, кровь — нет (модуль «Боец поневоле» — тексты-тренировки самообороны без изображений насилия; если сомнение — ответить «нет реалистичного насилия»).
- Сексуальный контент, нагота — нет. Нецензурная лексика — нет. Наркотики, алкохоль, табак — нет.
- Азартные игры / симулированные азартные игры — нет.
- Общение пользователей между собой, обмен контентом — нет. Передача местоположения — нет.
- Покупки в приложении — нет. Неограниченный доступ в интернет через приложение (браузер) — нет (браузер «Тихо» в play-сборку не входит).
Ожидаемый результат: 3+ / PEGI 3 / «0+».
