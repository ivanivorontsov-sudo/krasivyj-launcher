# Уют — красивый и лёгкий лаунчер для Android

Домашний экран на Kotlin + Jetpack Compose: 16 продуманных тем, которые меняют **шрифты, цвета, форму иконок, сетку, отступы, обои и анимации**, 40 шрифтов с проверенной кириллицей (17 рукописных), живые плитки, быстрый поиск с транслитом. Без интернета, рекламы и трекеров.

* minSdk 26 (Android 8.0+), targetSdk 35, работает на любой частоте экрана (60–144 Гц)
* Нет разрешения `INTERNET` — приложение физически не может ничего отправить
* Release-сборка: R8 full mode + shrinkResources, подписана выделенным ключом (не debug)

**Важно (законность):** все темы — оригинальная работа по мотивам раскладок. Не используются логотипы, иконки, обои и фирменные шрифты Apple/Microsoft (SF, Segoe) — вместо них Inter и Open Sans (OFL). Названия тем — русские слова, а не торговые марки.

## Почему Kotlin + Compose, а не View

* Плавные анимации (пружины, турникет, 3D-перевороты плиток, параллакс) пишутся декларативно, а значения каждого кадра читаются только внутри `graphicsLayer {}` / `draw {}` — **без рекомпозиции на кадр**.
* R8 full mode вырезает неиспользуемый Compose: код весит около 2–3 МБ; большая часть APK — шрифты.
* Baseline profile (`app/src/main/baseline-prof.txt` + profileinstaller) — предкомпиляция стартового пути, чтобы первый запуск не «тормозил».
* Стабильность классов объявлена в `compose-stability.conf`, чтобы списки не перерисовывались зря.

## Системный шрифт — честно

Android не позволяет обычному приложению сменить шрифт всей системы: нужен root или фирменный магазин тем (Samsung FlipFont требует подписи Monotype). Поэтому:

* Уют меняет шрифты везде, где рисует сам — часы, подписи, меню, плитки, виджет-карточки.
* Кнопка «Открыть настройки шрифта телефона» ищет экран шрифтов производителя (Samsung, Xiaomi, realme/OPPO/OnePlus → «Темы», Huawei, vivo…) с запасными вариантами (настройки экрана → общие настройки).
* «Установить обои темы» ставит нарисованные обои на телефон, и на Android 12+ Material You сам перекрашивает системные акценты под тему — законный способ «темизировать» систему.

## Функции

* HOME-активность, док, страницы, перемещение/удаление иконок, переименование и скрытие
* Меню приложений: мгновенный поиск RU/EN, транслит (`ютуб` → YouTube, `kamera` → Камера), неверная раскладка (`ntktuhfv` → телеграм), инициалы (`gpm`), поиск по пакету, Ё=Е, учёт частоты запусков; строка «Искать в интернете» и «в магазине»
* Долгое нажатие: ярлыки приложений (LauncherApps shortcuts), «О приложении», «Удалить», закрепить, размер плитки
* Жесты: свайп вверх — меню, вниз — шторка, двойное касание — блокировка (необязательно)
* Виджеты (AppWidgetHost) на странице «Сегодня», изменение высоты и порядка
* Наборы иконок (ADW/Nova/GO/TeslaCoil), монохромные иконки для плиток
* Часы/дата (без погоды и интернета), ближайший будильник
* Живые плитки: часы (переворот → день и будильник), **Фото** (Ken Burns + перевороты, разрешение спрашивается только при закреплении), календарь (ближайшее событие), счётчики уведомлений. Плитки обновляются со случайными интервалами, анимации останавливаются вне экрана, в режиме энергосбережения и при отключённых анимациях
* Рабочий профиль: приложения всех профилей с бейджем, обработка установки/удаления/обновления пакетов и смены языка

## Плавность и realme UI

* Запрашивается **максимальная частота при текущем разрешении** (`preferredDisplayModeId`) — на realme 15 5G это 144 Гц; переключатель в «Плавность и батарея».
* Все анимации считаются по времени (spring/tween), а не по кадрам — одинаковы на 60/90/120/144 Гц.
* Уважает «Убрать анимации» / масштаб длительности анимаций (`ValueAnimator.areAnimatorsEnabled`).
* Открытие приложений из иконки через `makeScaleUpAnimation` / `makeClipRevealAnimation`.
* Кнопка исключения из оптимизации батареи и подсказки для realme/ColorOS, Xiaomi, Samsung, Huawei — показываются только на этих брендах.
* Размытие окна позади меню (Android 12+, если поддерживается); иначе — дешёвая «матовая» копия обоев.
* JankStats в debug-сборке (`adb logcat -s UyutJank`).

## Известные ограничения

* Системный шрифт без root не меняется (см. выше).
* Анимации жестов «домой/недавние» для сторонних лаунчеров на большинстве прошивок (в т.ч. realme UI) упрощены системой — это ограничение Android/OEM (QuickStep доступен только системному лаунчеру).
* Блокировка двойным касанием требует включить службу спец. возможностей; на Android 13+ для установленных не из магазина APK сначала нужно «Разрешить ограниченные настройки».
* Ярлыки по долгому нажатию работают, только когда Уют выбран лаунчером по умолчанию.
* Виджеты размещаются на отдельной странице столбиком, а не в свободной сетке; запросы приложений «закрепить ярлык» не поддерживаются.
* Системные обои нельзя размыть или показать внутри плиток (Android не даёт их читать) — для этого используются обои темы или своё фото.
* Baseline profile написан вручную (без macrobenchmark).

## Сборка

```bash
export JAVA_HOME=/path/to/jdk-17 ANDROID_HOME=/path/to/Android/Sdk
./gradlew testReleaseUnitTest assembleRelease
```

Release собирается **только** выделенным ключом: локально — `keystore.properties` (не в git), в CI — секреты `SIGNING_KEYSTORE_BASE64`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`. Без ключа release-задача падает, подписи debug-ключом не бывает. CI проверяет SHA-256 сертификата и публикует APK в GitHub Releases при теге `v*` (artifact-хранилище не используется как основной канал).

SHA-256 сертификата подписи: `73:B8:37:77:5D:17:EB:48:CA:09:8D:E3:62:D1:DC:1B:C5:29:EC:35:1F:82:E6:79:99:44:44:25:86:8B:CE:35`
